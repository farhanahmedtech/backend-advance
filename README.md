# 🔐 Complete Authentication System

This project is a complete authentication system built using:

- Express.js
- MongoDB
- Mongoose
- JWT (JSON Web Token)
- bcrypt (for password hashing)

---

## 🚀 Features

- User Registration
- User Login
- Password Hashing using bcrypt
- JWT Token Generation
- Protected Routes
- MongoDB Database Integration

---

## 🛠 Technologies Used

- Node.js
- Express.js
- MongoDB Atlas / Local MongoDB
- Mongoose
- JWT
- bcrypt
- dotenv
